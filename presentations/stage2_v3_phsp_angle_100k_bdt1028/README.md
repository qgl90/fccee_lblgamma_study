# PHSP angular acceptance PI deck

Run `bash build.sh` from this directory. The four slide figures are copied
without edits from `docs/figures/stage2_v3_phsp_angle_100k_bdt1028/`.
The generating command, exact inputs, model and score are recorded in
`howto/v3_phsp_angle_acceptance.md` and
`docs/STAGE2_V3_PHSP_ANGLE_REVIEW_2026-10-04.md`. The exact bin counts,
fit response matrix and residual summaries are in
`docs/data/stage2_v3_phsp_angle_100k_bdt1028/acceptance_resolution.json`.
This is a named frozen-score scenario; changing the BDT calls for a new deck.
