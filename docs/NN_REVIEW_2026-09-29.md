# PI review: dense neural net for Λb→Λγ candidate selection

## Question and frozen reference

Can a neural network improve post-preselection signal retention while
rejecting generic Winter2023 IDEA Zbb combinations in the Λb signal-mass
region? This comparison uses exactly the same candidate reconstruction,
fitted-Λ `|m(pπ)−1.115683|<10 MeV` offline window, truth labels, and
train/validation/test partitions as the [BDT review](BDT_REVIEW_2026-09-29.md).
The FCCAnalyses candidate builder remains unchanged. Its Λγ fit range is
4.9–6.3 GeV. A 5.4–5.9 GeV interval is only a peak-background diagnostic.

## Inputs, architecture, and controls

The input audit contains 10,000 generated forced PHSP signal events,
10,000 forced Λη events, and 1,000,000 central Winter2023 IDEA Zbb events.
The post-Λ table has 5,552 true PHSP and 8,063 generic Zbb candidates.
Zbb source files 0–6 train, file 7 validates, and files 8–9 test; PHSP
candidates use an event-hash split. The independent 10k HELAMP sample and
Λη feed-down are scored only after training.

`studies/reconstruction/train_postlambda_nn.py` trains three dense
64→32→1 candidates with dropout and L2 regularization: a compact 23-input
set, all 39 allowed reconstructed inputs, and a compact set without the
two strongest closure inputs. Median imputation, missing flags, robust
scaling, clipping, class weights, and early stopping use training and
validation only. Validation AUC chooses the input set; test files are
opened for the frozen comparison afterward. The selected variant is
`all_reco`, with 39 inputs and 54 training epochs.

The network sees fitted Λ topology, daughter-removed photon isolation,
candidate/hemisphere kinematics, and ROE/recoil closure. It does **not**
see Λγ mass, reconstructed or truth cosθp, truth ancestry, source/event
identifiers, or Λb charge sign. The definitions and units of all 39 inputs
are in [BDT_FEATURES.md](BDT_FEATURES.md); they are shared with the BDT.
Validation-only whole-group permutation reduces AUC by 0.0684 for Z
closure/ROE, 0.0314 for photon isolation/partner, 0.0129 for fitted Λ
topology, and 0.0057 for kinematics/hemisphere. This describes learned
dependence, not a causal feature ranking; the closure features may encode
local-forced-signal versus central-Zbb production differences.

## Held-out result

The NN test AUC is **0.99862**, compared with **0.99896** for the BDT on
the identical 811 true PHSP and 1,655 generic Zbb post-Λ candidates.
The `sig80` NN threshold of **0.98757** is set from validation signal
only. It keeps **646/811** test signal candidates (79.7% relative to
post-Λ test signal) and **0/1,655** test Zbb candidates. The 646
truth-matched candidates correspond to 646 distinct test signal events
out of 1,486 generated PHSP test decays, or **43.5%** absolute acceptance
× reconstruction × NN selection efficiency. The BDT at its
own validation `sig80` threshold keeps 621/811 and 0/1,655. Thus the NN
retains 25 more test signal candidates at this sampled rejection level;
the present Zbb sample cannot distinguish the true extreme-tail rejection.

Inside 5.4–5.9 GeV, the NN keeps 628/793 test signal, 0/526 test Zbb,
and 547/732 true Λη feed-down candidates. It retains 4460/10,000
generated HELAMP events as matched post-Λ NN candidates (44.6% absolute
forced-event efficiency). The generated-angle acceptance figure and
mass/cosθp shape checks are saved next to the NN model; these must be
reviewed before a polarization fit.

## Purity and statistics

With zero Zbb candidates in the current 200k-event independent test,
the approximate one-sided 95% Poisson upper is three MC events. In the
editable 5×10¹²-Z scenario one test Zbb candidate carries weight
3.78 million, giving an **11.34 million** expected peak-background
upper count. The same scenario projects about **344,000** peak signal
candidates and **16,300** Λη candidates at NN `sig80`. Its 2.94%
“purity using Zbb count upper” mixes a background upper with the
assumption that *all* b baryons at the Z are Λb; it is **not** a physical
purity confidence bound. No high-purity claim follows from zero observed
test survivors.

The full central campaign metadata lists 438,738,637 Zbb events. With
the NN now frozen, every new central file can be an independent test.
Using the NN `sig80` peak signal and η yields above, zero Zbb survivors,
and an exact one-sided 95% Poisson count upper, about **6.91 million
independent test Zbb events** would be needed for the illustrative 50%
peak-purity ratio; about 103 million would be needed for 90%. The true
requirement may be higher if rare Zbb candidates survive. This is a
different allocation from the earlier 20%-test planning calculation.
Additional source IDs 10–77 are being processed toward 7.0 million
total independent test events, counting the original two 100k test
files. **Both model and thresholds stay frozen.**
The original ten-file reconstruction took approximately three hours for
one million events with ten jobs × four threads; the 68-file extension
therefore spans many hours. `scripts/continue_nn_extension78.sh` waits
for source IDs 10–19, then runs the remaining sources, flattens, scores,
and refreshes the slides. The ten-file batch logs are
`outputs/logs/zbb_training_chunk10.log` through `chunk19.log`.

## Decision gate

The NN is a valid alternative working point, with slightly higher held-out
signal retention than the BDT at a sampled zero-Zbb point. Keep both
scores and the stage-1 audit. A final reference selection needs a much
larger **independent** Zbb tail study, a Λb-specific Z-pole production
fraction, and a check that the closure features generalize between
matched-campaign signal and background production. Do not promote the
current NN score cut solely from this one-million-event baseline.
